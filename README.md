# Project Title
Where Songs Live: an exploration of musical spaces 
## Project Option
Website 

## Project Description
I want to explore the way that music is available to people in certain spaces, the way people respond and react to music in their daily life and how people are able to engage with music in different environments. My goal with my responsive website is to show where music inhabits and how it shapes different emotions. Listening to music on the bedroom, cars at concerts, record stores. Making the user have an immersive experience of what it is like to experience a song for the first time, or what kind of spaces does it cover.
\
The user will be able to choose their own adventure on a museum style experience where it takes you on different paths with the click of images in the main first page. After choosing their path, they will discover the experiences of music and different playlists to enhance the interaction. 

## Theme Interpretation
with my project, I want to explore the idea of space in a more metaphorical way. I was interested in the digital spaces that people are exposed to today, and how that related to how they consume media,  their exposure to the world and curated their own ideas, likes and dislikes.  In the digital world, spaces look more like niche spaces that are customizable to an individual. But also how things that are not tangible can inhabit spaces, media like movies or music that have become more digitized than ever have a different place within spaces than before. 

## Intended User or Player
As music can be experienced by a wide range of individuals, the intended audience can vary. Mostly people from ages 18-25 because that specific demographic are prone to going to concerts, record stores and experiencing music more often. 

People that enjoy festivals and concerts are also the main target audience, the user doesn’t need to have a qualified experience to engage with the responsive page, since it is formatted more of an informational, immersive experience.

## User or Player Goal
The expectation is for users to browse an atmospheric site that makes them learn more about music spaces and where to find them, as well as reflect on the way that users engage with media. 

## Main Features
Interactive Room Selectors: Clickable sections representing differen music spaces 

Dynamic Visual Elements: animated layout elements that react to user input.

Custom Card Layouts: Clean, structured product/space detail cards displaying information about each audio environment.

Responsive Navigation: Seamless menu and layout adjustments for desktop and mobile screens

## Responsive Design
The website uses a CSS flexbox grid and media queries that ensure that the website is structure with a set but fluid scaling system. Major interactions are fitting all the cards in smaller screen and veryfying all clickable elemnts are accessible. 

## User Testing

My interface was very successful through the process of guiding the user efficiently and smoothly. The choose your adventure button was very easy to understand and find, as well as the different paths that the player was going to click and look at the information from that particular page. What users found the most confusing was the navigation buttons. Tasks like going between pages after the adventure options becomes a little difficult because I only have a home button that takes you to the same page, and a spaces button that doesn’t work yet. The stacked circles after the explore more! Button we’re also a little inconclusive because at first it seems like normal hovers, and some of the testers didn’t think it was clickable. I think that maybe making the buttons more apparent, adding more buttons to go back between pages and making the explore more! Buttons more visible will be the most improvement. 

## Revisions
Fixed overflowing and stacking cards: I made a more flexible layout that adapted better into smaller screens, by stacking them vertically it made it easier for the user to browse and more adatable.

Adding more menu buttons: I added more buttons to go back between pages so that the user was able to browse through the website very smoothly 

Clickable Interaction lagging: I made sure that all interactions were usable and the javascript did the right hovers so that the page wouldn't;ag with each interaction.
